# ספר/מספרה מקצועית

אתר דוגמה לספר/מספרה עם טופס קביעת תור.

## קבצים בפרויקט

- `index.html` - דף הבית והאתר כולו
- `styles.css` - עיצוב האתר
- `script.js` - טיפול בטופס קביעת התור
- `ספרים-מספרות-אתר-מוכן.md` - מסמך הצעה ותוכן
- `PUBLISHING_INSTRUCTIONS.md` - הנחיות לפרסום לאינטרנט

## איך לפרסם ב-GitHub Pages

1. צור ריפוזיטורי חדש ב-GitHub.
2. הוסף את הקבצים מהתיקייה הזו לריפוזיטורי.
3. דחוף את הקבצים לענף הראשי (`main` או `master`).
4. ב-GitHub, עבור ל-Settings > Pages.
5. בחר ענף (`main` או `master`) ושמור.
6. המתן כמה דקות וקבל את הכתובת:
   `https://USERNAME.github.io/REPO_NAME`

## קישורים מועילים

- GitHub Pages: https://pages.github.com/
